# Resume shablonlari

1. `01_ATS_Classic_Resume_Template.docx`
   Eng universal variant. Bank, ofis, support, sales, operations, admin, accounting va ko'p kompaniyalar uchun mos. ATS tizimlar juda yaxshi o'qiydi.

2. `02_Modern_Tech_Resume_Template.docx`
   IT, developer, data, QA, product, design yoki texnik projectlar uchun mos. Skill matrix bor, lekin baribir ATS-friendly.

3. `03_Leadership_Impact_Resume_Template.docx`
   Senior, manager, team lead, business, project management yoki natija/raqam ko'p bo'lgan profillar uchun mos.

Tavsiya: Agar qaysi rolga topshirishingiz aniq bo'lmasa, 01 variantdan boshlaymiz. Agar IT yo'nalish bo'lsa, 02. Agar tajriba va natijalar kuchli bo'lsa, 03.
